# Security policy

The first Windows release is still under development. Security fixes target the current `main` branch; no older released version has a support commitment yet.

Report a suspected vulnerability through [GitHub's private vulnerability report](https://github.com/BharathKmalviya/Aggressive-Pomodoro/security/advisories/new). Private vulnerability reporting is enabled for this repository. Include the affected version or commit, reproduction steps, impact, and any safe proof of concept. Avoid posting exploit details or private data in a public issue.

The maintainer will review reports in the private advisory thread and coordinate a fix and disclosure there. There is no guaranteed response or patch deadline. For ordinary bugs, use a [public issue](https://github.com/BharathKmalviya/Aggressive-Pomodoro/issues/new).
